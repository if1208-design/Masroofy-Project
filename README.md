
# Masroofy-Project
Project Name:
Masroofy Project

Project Description:
A web application developed using Django to help users manage expenses and track budgets efficiently.

Tools and Technologies Used:
- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- GitHub

Project Structure:
- templates/: HTML pages
- static/: CSS, JS, images
- models.py: Database models
- views.py: Application logic
- db.sqlite3: Database file

How to Run the Project:
1. Install Python
2. Install Django using:
   pip install django

3. Open terminal in project folder

4. Run:
   python manage.py runserver

5. Open browser and go to:
   http://127.0.0.1:8000/
